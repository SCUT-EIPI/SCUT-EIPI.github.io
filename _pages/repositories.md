## 🧬 Symbolic Regression & AI for Science

- [**GP-and-its-applications**](https://github.com/SCUT-EPII/GP-and-its-applications): Open-source implementations, benchmarks, and tutorials for Genetic Programming, symbolic regression, and automated rule discovery.
- [**Self-learning-Gene-Expression-Programming**](https://github.com/SCUT-EPII/Self-learning-Gene-Expression-Programming): Official implementation for Self-Learning Gene Expression Programming (SL-GEP) in adaptive function discovery (*IEEE TEVC*).
- [**Multiform-GP**](https://github.com/SCUT-EPII): Multiform genetic programming framework designed for solving high-dimensional symbolic regression problems (*IEEE TEVC 2025*).
- [**Evolving-Equation-Learner**](https://github.com/SCUT-EPII): Neural-evolutionary hybrid architecture for symbolic regression and discovering governing physical laws (*IEEE TEVC 2024*).
- [**Infinite-Recursive-GP**](https://github.com/SCUT-EPII): Automated discovery of infinite recursive mathematical conjectures via genetic programming (*IEEE TEVC 2025*).

<br>

## ⚡ Evolutionary Multitasking & Transfer Optimization

- [**EMO-AEA (Explicit Autoencoding MTO)**](https://github.com/SCUT-EPII): Official implementation of evolutionary multitasking via explicit autoencoding for high-dimensional cross-domain optimization (*IEEE TCYB*).
- [**Adaptive-MFEA**](https://github.com/SCUT-EPII): Adaptive knowledge transfer framework for multifactorial evolutionary computation (*IEEE TCYB*).
- [**Many-Task-Evolutionary-Framework**](https://github.com/SCUT-EPII): Archive-based evolutionary framework for simultaneous solving of many-task optimization problems (*IEEE TETCI Outstanding Paper Award*).

<br>

## 🤖 Reinforcement Learning & Complex Systems

- [**HGFF-WSN**](https://github.com/SCUT-EPII): Deep reinforcement learning framework with hybrid graph features for sensor lifetime maximization in wireless sensor networks (*IEEE TAI 2025*).
- [**DRIFT-Crowd-Control**](https://github.com/SCUT-EPII): Dynamic crowd inflow control system utilizing LSTM-based deep reinforcement learning (*IEEE TSMC 2025*).
- [**Explainable-Traffic-GP**](https://github.com/SCUT-EPII): Explainable traffic signal control for urban networks through genetic programming (*Swarm and Evolutionary Computation 2024*).
